06 · Bootstrap 5.3 Integration

Applying Tokens in Sevro/wwwroot/css/site.css

tokens.css maps both Bootstrap 5.3's native --bs-* variables and Sevro's existing --sc-* variables so existing Razor views upgrade cleanly without breaking any Bootstrap layout classes. 

<!-- 1. Add Plus Jakarta Sans alongside Inter in Sevro/Views/Shared/_Layout.cshtml -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Plus+Jakarta+Sans:wght@600;700;800&display=swap" rel="stylesheet" />

<!-- 2. Load tokens.css right after Bootstrap 5.3 and before site.css (or paste into site.css) -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" />
<link rel="stylesheet" href="~/css/tokens.css" asp-append-version="true" />
<link rel="stylesheet" href="~/css/site.css" asp-append-version="true" />
